Palette matrix - every --color-<class><letter>

nick-palette in _palette.scss. Rows are the 32 color classes, columns the 26 first letters; each cell is the color a nick actually gets. The axis headers are the two source palettes, --color-1..32 (_dark-theme.scss / _light-theme.scss) and --color-A..Z (test/theme-debug.scss).
Hue lerps 70% from the letter toward the class, and saturation and alpha come from the letter; lightness is re-derived at the shifted hue, then offset by however far the letter sat from its own baseline - so a column varies in lightness rather than being flat. The axis headers won't match their own row or column: the matrix looks the letter up through $shuffle-letters / shuffle-index in _palette.scss.

Name-prefix rules

$name-styles in _palette.scss, emitted after the color loop in theme.scss. These match on the name alone and are written to beat the color loop, so where both set the same property the name rule wins - shown at three color classes so you can confirm it is consistent across them.
